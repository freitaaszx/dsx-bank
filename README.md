# 🏦 Bank System (C# Console)

Um sistema simples de banco desenvolvido em C# para rodar no console.
Projeto criado com fins de aprendizado, abordando conceitos básicos de programação.

---

## 🚀 Funcionalidades

* 🔐 Verificação de senha
* 💰 Consulta de saldo
* 💱 Conversão de moeda (Real → Dólar / Euro)
* ⚙️ Menu de configurações
* ❌ Encerramento automático em caso de erro

---

## 🧠 Conceitos utilizados

* Estruturas condicionais (`if`, `else`)
* Estrutura de repetição (`while`)
* `switch case`
* Entrada de dados com `Console.ReadLine()`
* Conversão de tipos (`int`, `double`)
* Encerramento de programa com `Environment.Exit()`

---

## ▶️ Como executar

1. Instale o .NET SDK
2. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/bank-system-csharp.git
```

3. Entre na pasta:

```bash
cd bank-system-csharp
```

4. Execute o projeto:

```bash
dotnet run
```

---

## 📌 Observações

* Este projeto é apenas educativo (não possui segurança real)
* Não armazena dados
* Não possui criptografia de senha
